# Claude Code + Obsidian Integration

Obsidian's local markdown files make it a natural fit for Claude Code — it can directly read, write, and restructure your vault, turning it into a highly automated second brain.

---

## Core Integration Capabilities

### CLI Mastery
Claude Code connects to Obsidian's CLI, giving it access to 95+ commands. Install the relevant skills to let Claude Code analyze, edit, and restructure notes seamlessly.

### Automated Vault Setup
Starting fresh? Claude Code can interview you about your work and personal life, then automatically draft and build a personalized vault structure. It can also take stray inbox thoughts and auto-categorize them into the correct folders.

### Deep Note Analysis
Point Claude Code at your vault and ask it to analyze notes over a specific timeframe (e.g. the past 45 days). It can:
- Summarize overarching themes
- Track your focus areas
- Count how often you use specific concepts or words

### Document Processing
Claude Code can organize messy external folders of JSON files or large PDFs. Working alongside other tools, it can:
- Break down hundreds of pages into concise markdown cheat sheets
- Auto-import them into Obsidian
- Map out the process on a visual canvas

### Web Research & Metadata
Spin up Claude Code as a research agent to:
- Search the web for images of people you have notes on and populate file metadata automatically
- Use slash commands like `/tlddr` to summarize long conversations and log next steps directly into Obsidian

---

## Best Practice: Protect Your Idea Verse

Keep Claude Code generations in a **dedicated "AI zone"** or a completely separate vault. This creates healthy friction — you only manually bring in the AI insights you truly value, ensuring your own voice stays dominant.
